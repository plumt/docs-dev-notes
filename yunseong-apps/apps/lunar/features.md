# Lunar - 기능별 상세

각 항목은 feature 모듈 하나에 대응한다. 모든 화면은 `XxxScreen` 하나만 공개하고 본문 컴포저블은 숨긴다.

## 홈 (`feature:home`)

오늘의 달 위상 대시보드이며 시작 탭이다.

- 표시: 위치 칩, 달 이미지(Canvas), 위상 이름·설명, 조도(%), 음력 일자, 보름달까지 남은 일수
- 다가오는 위상 타임라인: 이번 달만 보면 월말에 목록이 비어 다음 달까지 이어서 고른다
- 현재 위치 기준 월출·월몰과 기상청 하늘상태·강수로 판단한 "달 보기" 정보. 한국 밖 좌표에서는 기상청 예보를 부르지 않는다
- 예보가 실패하면 같은 높이의 실패 카드와 다시 시도 버튼을 둔다
- 미읽음 알림 수를 알림함 진입 버튼에 표시
- 기준 시각은 지금과 자정마다 갱신해 자정을 넘겨도 낡은 상태가 남지 않는다

## 달력 (`feature:calendar`)

- 월 이동과 격자/목록 두 탭. 탭 전환은 재적재 없이 같은 목록을 다른 모양으로 그린다
- 격자에서 날짜를 누르면 그날의 상세 카드를 보인다. 칸 하단 영역 높이를 고정해 레이블 유무와 무관하게 달 크기가 같다
- 삭망 날짜에 이벤트 이름과 시각, 블루문이면 "블루문" 표시
- 목록 탭은 줄 사이에 네이티브 광고를 끼운다. 광고가 비면 빈 자리가 남지 않는다
- 적재 실패를 상태로 알리고, 머리글과 탭은 항상 남겨 다른 달로 넘어갈 수 있다

## 달 탐구 (`feature:explore`)

- 그 해의 블루문·슈퍼문·미니문을 시간순으로 나열. 지난 항목도 흐리게 두고 빼지 않는다(그 해 전체를 보여 주는 화면이라서다)
- 거리는 만 단위 km 로 표시한다. 네트워크 의존 없이 전부 로컬 계산이다
- 슈퍼문·미니문 분류 기준은 천문학의 단일 정의가 없어 앱이 정한 거리 기준을 쓴다

## 이달의 하늘 (`feature:sky`)

- 한국천문연구원(KASI) 월별 해설 글과 천문현상 일정을 한 장의 카드에 담는다
- 일정을 누르면 위키백과 요약을 바텀시트로 보인다. 일정 문구 속 영어 약어는 한국어로 바꿔 보인다
- 오늘 일정에 "오늘" 표시, 지난 일정은 흐리게
- 위상 일정은 앱 계산 값을 따라 홈·달력과 같은 시각을 보인다
- 달을 옮기면 앞 요청을 취소하고 같은 달일 때만 결과를 반영해 늦게 온 응답이 덮어쓰지 않게 한다
- 위키백과 출처·라이선스·원문 링크와 KASI 출처 표기를 지우지 않는다

## 설정 (`feature:settings`)

- 달 알림 토글 2종(달의 위상 / 특별한 달)과 정보 행(앱 버전·공지사항·이용약관·처리방침·광고 동의 변경·문의·오픈소스 라이선스), 광고 제거 구매·복원
- 화면 뼈대와 정보 행 순서는 공용 `SettingsScaffold` 가 정한다. 광고 동의 변경 행은 동의 양식이 필요할 때만 보인다
- 켜기 흐름: 알림 권한 확인 -> 필요 시 시스템 요청 -> 거부면 안내 다이얼로그 -> 토픽 구독이 성공해야 ON 저장
- 설정값은 네이티브 설정을 직접 읽지 않고 래퍼를 거친다

## 알림 (`feature:notification`)

달 이벤트 FCM 메시지를 로컬 알림으로 바꾸는 핸들러와 알림함 화면이다. 의존에 추가하면 핸들러가 라우터에 자가등록된다.

| 갈래 | 이벤트 |
|---|---|
| 달의 위상 | 새 달, 보름달 |
| 특별한 달 | 슈퍼문, 미니문, 블루문 |

- 본문은 서버가 보낸 문구를 우선 쓰고 없을 때만 종류별 기본 문구로 떨어진다. 그래서 문구는 서버 배포만으로 바뀐다
- 새 알림이 이전 달 알림 자리를 덮는다
- 모르는 이벤트는 표시하지 않는다(모르는 이벤트를 켜진 것으로 보는 쪽이 더 나쁘다)
- 실패는 핸들러가 삼키지 않고 공용 FCM 서비스가 받아 보고한다

## 스플래시 (`feature:splash`)

- 공용 `SplashScaffold` 로 보름달 로고 페이드인을 그리고, 끝나면 버전 확인을 시작한다
- 확인에 실패하면 캐시가 있어도 진행하지 않고 공용 연결 안내(다시 시도)에서 멈춘다. 강제 업데이트가 필요하면 공용 업데이트 다이얼로그가 막는다
- 홈 route 를 모르고 콜백으로만 이동한다. 홈으로 넘길 때 스플래시를 백스택에서 걷어낸다

## 공통 (`core:common`)

- 달 위상 그림(`MoonPhaseImage`), 위상 이름 구간, 날짜·거리 포맷, 표시 모델
- 조도는 한 함수로만 내 홈·달력이 같은 값을 보인다
- 알림 설정 저장소(DataStore). 저장 키와 파일 이름은 바꾸면 기존 설정이 사라진다
- 테마: Midnight 팔레트 + 달 그림 색. 목록 광고 행 모양도 여기서 한 곳으로 정한다

## 촬영용 데이터 (`core:demo-seed`)

- 첫 실행 알림 안내를 거친 상태로 만들고 알림함에 달 알림을 심는다. 날씨 상태도 debug 빌드에서만 강제할 수 있다
- 공용 `DemoSeeder` 포트의 구현이고 앱이 쓰는 저장소 경로로만 심는다. 가짜 서버 값을 만들지 않는다

## 테스트

- 앱 모듈: DI·내비게이션 테스트, 홈·달력·하늘의 위상 이름·시각 일치 테스트, 광고 있음/없음 셸 스크린샷 테스트
- 화면 모듈: ViewModel 단위 테스트와 스크린샷 테스트(글자 배율 2.0 배치 포함)
- Appium E2E: 저장소 공용 러너 위에 앱은 설정·시나리오만 둔다. dev 플레이버, 콜드 스타트 스모크
- 접근성 testTag 는 앱 셸이 resource-id 로 노출한다
